# Lifunia.github.io
Guides, documentation, and support for Lifunia apps.

日本語版は `/`、英語版は `/en/` に配置しています。トップページ、Sauna Timer、ととねるの各ページは、ヘッダーから言語を切り替えられます。
本文を変更する際は、対応する英語版の `index.html` も更新してください。CSS、スクリーンショット、ととねるの操作用JavaScriptは両言語で共用しています。

各ページの更新履歴は、それぞれの `index.html` 内の `id="changelog"` に記載します。
ページを更新したら、`changelog-list` の先頭に日付（`time` の `datetime` は `YYYY-MM-DD`）と変更内容を追加してください。同日の変更は1件にまとめます。
Webページの変更を記載します。アプリの変更も掲載する場合は、アプリ側のリポジトリで日付・バージョン・機能を確認し、アプリ名とバージョンを明記してください。
