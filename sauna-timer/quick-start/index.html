Sauna Timer

クイックスタートガイド

サウナ・水風呂・休憩の計測から終了まで、基本の操作をまとめました。

各機能の詳しい説明はSauna Timerページをご覧ください。

始める前に：Garmin Connectに記録する方は、FIT SaveをONにしてください。計測開始後は変更できません。記録しない方はOFFのまま使えます。

ボタンを確認

  • 赤丸 ENTER: 右上 (GPS)
  • 青丸 BACK: 右下 (SET)
  • 紫丸 UP: 左中央 (MENU)
  • オレンジ丸 DOWN: 左下 (ABC)
  • 赤丸 ENTER: 右上 (START / STOP)
  • 青丸 BACK: 右下 (BACK / LAP)
  • 紫丸 UP: 左中央 (MENU)
  • オレンジ丸 DOWN: 左下 (DOWN)
  • 赤丸 ENTER: 右上 (START / STOP)
  • 青丸 BACK: 右下 (BACK / LAP)
  • 紫丸 UP: 左中央 (MENU)
  • オレンジ丸 DOWN: 左下 (DOWN)

図は代表機種です。ボタンの印字は機種によって異なります。このガイドではENTER／BACK／UP／DOWNと呼びます。

切り替えて、終了する

  1. 開始する

    アプリの起動画面でENTERを押すと、サウナの計測が始まります。

  2. サウナ → 水風呂 → 休憩

    時間が来て振動したら、少し待ってENTER。次の時間の計測が始まります。休憩後も同じ操作で次のセットへ進みます。

    残り時間を短くしたいとき

    タイマー動作中にDOWNを素早く2回。サウナ・休憩は30秒、水風呂は10秒ずつ短縮します。いずれも残り10秒まで短縮できます。

  3. 終了する

    BACKを素早く2回 → UP／DOWNでYES → ENTER。結果画面が出たらENTERまたはBACKで閉じます。

時間前に切り替えたいとき

ENTERでTimer Menuを開き、UP／DOWNでNext Timerを選んでENTER。

FIT保存する（任意）

Garmin Connectの指標を厳密に管理している方へ

FIT保存した記録は、同期するとGarmin Connectのアクティビティに登録されます。消費カロリーや、機種によってはトレーニング効果・負荷などの指標に影響する場合があります。

影響を避けたい方は、FIT SaveをOFFにして使用してください。初期値はOFFです。設定は次回も引き継がれます。

  1. 計測開始前に、起動画面でDOWN → UP／DOWNでSettingを選択 → ENTER。
  2. UP／DOWNでFIT Saveを選び、ENTERでON。BACKを2回押して起動画面へ戻ります。
  3. 基本操作に沿って計測し、終了時にYESを選びます。保存後、Garmin Connectと同期してください。

保存条件：サウナを実際に60秒以上計測し、休憩まで進んだセットが1つ以上必要です。条件を満たさない場合は保存されません。
