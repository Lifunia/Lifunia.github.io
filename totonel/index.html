Android App

ととねる

サウナセッションの心拍と記録を、一覧・グラフ・スコアで振り返るためのAndroidアプリです。

アプリ概要

ととねるは、Sauna Timerで保存したアクティビティを閲覧し、振り返るためのAndroidアプリです。

心拍の変化やセットごとの傾向を確認できます。
過去の記録をもとに、休憩時間やセットの組み立てを振り返れます。

主な機能

セッションを一覧で整理
日時、滞在時間、施設、評価を一覧で見渡せます。
検索やカレンダー表示にも対応しています。
心拍の変化を確認
サウナ、水風呂、休憩ごとの心拍の変化をグラフで確認し、各セットを振り返れます。
Totonoi Scoreで傾向を把握
心拍から算出したスコアと体感評価を並べて、セッションの特徴を確認できます。

ダウンロード・インストール

Android端末にAPKファイルをダウンロードしてインストールします。

APKをダウンロード

インストール方法

  1. Android端末でこのページを開き、APKをダウンロードします。
  2. ダウンロードしたAPKファイルを開きます。
  3. 許可を求められたら「設定」を開き、使用中のブラウザやファイルアプリの「この提供元を許可」をONにします。
  4. 元の画面に戻り、「インストール」をタップします。
    完了したら「開く」をタップして起動します。

設定項目の名称は、端末やAndroidのバージョンによって異なります。
Androidのインストール手順も参考にしてください。

使い方

記録を振り返る
  1. ホーム画面のリストからセッションを選びます。
    カレンダー表示の場合は、日付を選び、その日の記録をタップします。
  2. 概要で評価・施設・日時・スコア・心拍を確認します。
  3. 分析・グラフで心拍の推移やセットの詳細、次回のヒントを確認します。

「評価前はScoreを隠す」がONの場合、Ratingを入力するまでScoreは表示されません。

セッションを同期する
  1. 起動時に自動同期する場合は、Settingsで起動時に自動同期をONにします。
  2. 手動で同期する場合は、ホーム画面を下にスワイプします。
  3. 同期結果は通知と、ホーム画面上部の同期ステータスで確認します。

前回の同期から1分が経過するまでは、再同期できません。
同期ステータスを開くと、最終同期日時、状態、コードを確認できます。

Intervals API Key（APIキー）の設定

初めて同期するときは、Intervals.icuのAPIキーを取得してアプリに設定します。

APIキーを取得する

  1. Intervals.icuにアクセスします。
  2. 左側のメニューから設定を開きます。
  3. 設定画面の下部にあるDeveloper Settingsまで進みます。
  4. API Keyの項目にあるviewをクリックします。
  5. ポップアップに表示されたAPIキーをコピーします。

APIキーは他者に知られないようにしてください。
コピーしたキーを公開ページやSNSに貼り付けないでください。

ととねるに設定する

  1. ホーム画面右上の歯車アイコンからSettingsを開きます。
  2. Intervals API Keyを入力し、保存をタップします。
  3. 接続テストで、接続に成功したことを確認します。

画面紹介

各画面で確認できる情報と、主な操作方法を紹介します。

セッション一覧画面の操作

赤枠検索ボタン
施設名とRatingで検索できます。
青枠Settingsボタン
設定画面（Settings）を開きます。
紫枠同期ステータス
タップすると、最終同期日時や同期の状態を確認できます。
緑枠各セッション
タップすると、そのセッションの詳細画面を開きます。

カレンダー表示画面の操作

赤枠日付
日付の下に「・」がある日は、記録がある日です。
日付をダブルタップすると、詳細画面を開けます。
青枠概要
日付をタップすると、その日の記録の概要が表示されます。
Ratingが未入力の場合、評価の星は表示されません。
「評価前はScoreを隠す」がONの場合、Ratingを入力するまでScoreは表示されません。
概要をタップすると、詳細画面を開けます。

セッション詳細画面の操作

赤枠表示切り替えボタン
表示する内容を切り替えられます。
概要
セッションの概要を確認できます。
分析・グラフ
セッションの詳細と、次回のヒントをまとめた「今日の改善インサイト」を確認できます。
青枠Scoreの切り替えボタン
標準スコアとRating+を切り替えられます。
  • 標準スコア：心拍データから算出するスコアです。
  • Rating+：過去の評価傾向を反映したスコアです。
    学習が進むまでは、標準スコアと同じ値になります。
水色枠心拍の切り替えボタン
グラフやScoreに使う心拍データを、元データと補正データで切り替えられます。
  • 元データ：取り込んだままの心拍です。
  • 補正データ：記録が途切れた部分や明らかに不自然な数値を整えた心拍です。

選択中のデータ名はスイッチの横に表示されます。

元データは、取り込んだ心拍を補正せずに使用します。
Scoreの計算方法はSauna Timerと異なるため、値が一致しない場合があります。

緑枠編集ボタン
Rating（体感評価）とLocation（施設名）を編集できます。
オレンジ枠スクリーンショットボタン
操作ボタンなどを隠してスクリーンショットを撮影できます。
紫枠？ボタン
各項目の説明を確認できます。
ピンク枠操作ボタン
セッションの再計算や削除などを行えます。
  • 再計算：Ratingを変更した後に、スコアを計算し直します。
  • 削除：アプリ内のセッションデータを削除します。
    Intervals.icuにデータが残っていると、次回の同期で再び取り込まれます。
  • Rating+学習から除外：セッションをRating+の学習から除外します。

基本情報の編集画面の操作

赤枠Rating
そのセッションの体感を星で評価できます。
入力済みの評価も変更できます。
青枠Location
利用した施設名を入力・変更できます。

分析・グラフ画面の操作

赤枠心拍データの切り替えボタン
グラフに表示する心拍データを、補正データと元データで切り替えられます。
補正データ
記録の途切れや不自然な数値を整えた心拍データです。
元データ
取り込んだままの心拍です。
青枠セットの切り替えボタン
セットを選ぶと、そのセットのグラフを確認できます。
「全体」を選ぶと、セッション全体のグラフを確認できます。
最初に表示する範囲はSettingsで選べます。
緑枠？ボタン
各項目の説明を確認できます。

セットごとの詳細

Set Score
セットごとの指標から算出したスコアです。
Depth
サウナで上がった心拍の、休憩中の下がり幅を示します。
心拍が大きく下がるほど、スコアが高くなります。
Speed
休憩に入ってから心拍が下がるまでの速さです。
心拍が短時間で下がるほど、スコアが高くなります。
Stability
休憩中の心拍の変動の小ささを示します。
心拍が安定し、休憩時間が十分あるほど高得点になります。

Settings：表示とバックアップ

Intervals.icuのAPIキー設定
APIキーが未設定の場合は設定案内が表示されます。
この画像は設定済みの状態です。
青枠ホーム画面の表示切り替え
ホーム画面のリスト表示とカレンダー表示を切り替えられます。
オレンジ枠評価前のScore表示設定
「評価前はScoreを隠す」は、初期状態でONです。
ON：Ratingの入力後にScoreを表示します。
OFF：入力前もScoreを表示します。
緑枠心拍の初期表示
最初に表示する心拍データを、元データと補正データから選べます。
初期状態は元データです。
選択中のデータ名はスイッチの下に表示されます。
ピンク枠Scoreの初期表示
最初に表示するスコアを、標準スコアとRating+から選べます。
初期状態は標準スコアです。
選択中のスコア名はスイッチの下に表示されます。
紫枠インポート／エクスポートボタン
施設名（Location）と体感評価（Rating）を保存・復元できます。
機種変更時のデータ引き継ぎなどに使います。

Settings：同期とデータ管理

赤枠起動時の自動同期設定
ONにすると、アプリの起動時にIntervals.icuと同期します。
青枠同期データの取得期間
同期するデータの取得期間を選べます。
オレンジ枠APIキー入力フォーム
APIキーを入力します。
紫枠操作ボタン
APIキーの保存、接続テスト、削除を行えます。
キーを入力すると、保存ボタンを操作できます。
緑枠ローカルデータ削除ボタン
端末内に保存された記録を削除します。
APIキーとアプリの設定は残ります。

掲載している記録、施設名、心拍、評価、スコアはすべて紹介用の架空データです。

利用について

記録を振り返る際の注意

ととねるは、セッションを記録して振り返るためのアプリです。
心拍やスコアは診断・治療・安全判断を目的とするものではありません。
体調に不安がある場合は、アプリの表示にかかわらず利用を中止してください。

サウナ施設のルールに従い、水分補給と休憩を十分に取りながら使用してください。
